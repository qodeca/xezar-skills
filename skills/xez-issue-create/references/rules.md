- **Gate reporting: collect everything, then report once.** Evaluate every gate before
  reporting any of them, and name all the failing ones together. Reporting the first
  failure and stopping teaches the reader to fix one thing, re-run, and discover the next
  — a full cycle per problem, when one report could have listed them all. A gate's result
  is one of five words: `pass`, `findings`, `unknown`, `not-applicable`,
  `evidence-unavailable`. Only `pass` and `not-applicable` are satisfied.
  **`unknown` is never a pass** — it says the check did not happen, which is not the same
  as the change being fine, and it is not a failure of the change either.
  `evidence-unavailable` does not pass: if the source could not be reached, nothing was
  verified, and exempting it would let anyone through by making the source unreachable.
  Say which gate produced which word, and never report a status you did not derive from
  an input you actually had.
